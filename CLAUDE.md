# Правила репозитория glory-piranhas-dashboard

- Язык интерфейса, документации и коммитов: русский. Коммиты в формате Conventional Commits (`feat:`, `fix:`, `docs:`…).
- Деньги только в целых центах (`spendCents`, `cpdCents`); float допускается лишь при чтении из таблицы и сразу переводится через `toCents`.
- CPD считается только внутри гео. Общий CPD команды не показываем.
- Бенчмарки и гео меняются только в `web/src/config.ts`.
- Любое изменение логики в `web/src/domain` сопровождается тестом в `web/test`. Логика Swift живёт в `PiranhasCore` и покрывается `XCTest`.
- Перед коммитом: `cd web && npm run check`. Сборка `.app` и `swift test` выполняются в CI (macOS).
- Изменения контракта данных: сначала `docs/data-contract.md`, потом скрипт и парсер.
- Крупные решения записываются в `docs/adr/NNNN-*.md`.
