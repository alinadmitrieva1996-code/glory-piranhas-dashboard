# Контракт данных: скрипт таблицы → приложение

`GET <ссылка /exec>?key=<секрет>` → `application/json`.

## Успех

```json
{
  "ok": true,
  "version": 1,
  "generatedAt": "2026-11-18T07:00:00.000Z",
  "spreadsheet": "BUYERS_ALL",
  "timezone": "Europe/Moscow",
  "rows": [
    { "buyer": "BUYER1", "date": "2026-11-16", "geo": "AR", "clicks": 310, "regs": 80, "ftd": 21, "spend": 412.5 }
  ]
}
```

| Поле строки | Тип | Откуда | Смысл |
|---|---|---|---|
| `buyer` | строка | имя листа `BUYERn` | идентификатор байера |
| `date` | `YYYY-MM-DD` | колонка B | день, в часовом поясе таблицы |
| `geo` | строка | заголовок блока `BUYERn - AR` (строка 1) | код гео |
| `clicks`, `regs` | целое | Click, Reg | справочно, на экране пока не показываются |
| `ftd` | целое | FD | первые депозиты |
| `spend` | число, $ | Spend | **чистый спенд Facebook без комиссий**, 2 знака |

Правила:
- отдаются строки за текущий и прошлый месяц (`CONFIG.MONTHS_BACK`), только с `spend > 0` или `ftd > 0`;
- итоги команды и гео считает приложение, суммируя строки байеров. Лист `TOTAL` не читается, потому что он зависит от выбранного в таблице месяца.

## Ошибки

`{ "ok": false, "error": "<код>", "message"?: "<текст>" }`

| Код | Причина |
|---|---|
| `unauthorized` | ключ не совпал |
| `not_configured` | в скрипте не запускали `setup()` |
| `internal` | исключение в скрипте, подробности в `message` |

## Расчёты в приложении

- Доллары переводятся в целые центы: `round(spend × 100)`.
- CPD = `round(спенд_центы / FTD)`; при FTD = 0 CPD не определён.
- «Вчера» = последний день, где у команды по всем гео спенд больше 0. Месяц = с 1-го числа месяца этого дня по этот день.
- Статус: выше бенча — красный (с процентом превышения); от 95% до 100% бенча — «у границы»; спенд без FTD — красный; без бенча — серый.
