# ADR 0001. Нативная оболочка на Swift + интерфейс на TypeScript в WebKit

- Статус: принято
- Дата: 2026-11-18

## Контекст

Нужно приложение для одного Mac (COO), которое повторяет уже согласованный веб-дашборд: вкладки гео, карточки, график CPD и спенда, таблица байеров. Требуются кнопка обновления, автообновление и подключение к Google Sheet. Логика CPD и статусов уже проверена на реальных данных.

## Варианты

| Вариант | Плюсы | Минусы |
|---|---|---|
| **A. SwiftUI-окно + WKWebView с интерфейсом на TS** | Настоящее Mac-приложение (меню, ⌘R, связка ключей, ~2 МБ); интерфейс и расчёты переносятся 1:1 и тестируются в Node; при желании тот же интерфейс можно открыть в браузере | Две технологии в репозитории |
| B. Полностью SwiftUI + Swift Charts | Всё на одном языке | Переписывать график и таблицы заново; логику не проверить вне Mac |
| C. Electron / Tauri | Привычный веб-стек | Electron весит ~150 МБ; Tauri требует Rust-цепочку; для одного пользователя избыточно |

## Решение

Вариант **A**. Swift отвечает за всё, что касается системы: окно, меню, таймер, сеть, связку ключей, кэш. TypeScript отвечает за расчёты и отображение. Страница сама в сеть не ходит (CSP `default-src 'none'`): данные ей передаёт Swift через `window.PiranhasApp.render(payload, meta)`.

## Последствия

- Расчёты покрыты тестами `node:test`, оболочка покрыта тестами `XCTest`.
- Чтобы добавить экран или метрику, достаточно изменить только `web/`.
- Сборка `.app` возможна только на macOS. Её делает GitHub Actions (ADR 0003).
