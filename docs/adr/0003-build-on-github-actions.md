# ADR 0003. Сборка .app на GitHub Actions, подпись ad-hoc

- Статус: принято
- Дата: 2026-11-18

## Контекст

Приложение нужно одному пользователю на одном Mac. Платного аккаунта Apple Developer нет. Приложение собирает не человек на Mac, а агент, у которого нет macOS.

## Решение

- Каждый push в `main` запускает сборку на `macos-15`: тесты web → тесты Swift → `build-app.sh`.
- Подпись **ad-hoc** (`codesign -s -`), без нотаризации. Для своего Mac этого достаточно. Если архив скачан браузером, при первом запуске нужно один раз нажать правый клик → «Открыть».
- Результат (`Piranhas-macos.tar.gz`, логи, `status.json`) принудительно пушится в ветку `builds`. Так сборку можно забрать обычным `git` и из приватного репозитория, а при ошибке логи доступны без входа в GitHub.

## Последствия

- В ветке `builds` всегда один коммит, история не растёт.
- Если приложение понадобится другим людям, понадобятся Developer ID и нотаризация (отдельный ADR).
- Ad-hoc подпись меняется с каждой сборкой, поэтому после обновления macOS может один раз спросить доступ к ключу в связке ключей. Нужно нажать «Всегда разрешать».
