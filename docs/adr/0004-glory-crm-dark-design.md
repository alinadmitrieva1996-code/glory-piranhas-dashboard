# ADR 0004. Дизайн — тёмная тема Glory Finance CRM, бенч редактируется в приложении

- Статус: принято (COO, 18.11.2026)
- Дата: 2026-11-18

## Контекст

Первый интерфейс повторял веб-дашборд и был мало информативен: акценты стояли не на тех цифрах. COO попросила взять дизайн финансовой CRM Glory (тёмная тема), сделать экран гео информативным и дать менять бенч прямо в приложении. Макет согласован в canvas «Дашборд байеры — экран гео (макет)».

## Решение

- Токены — из Figma-файла Glory Finance CRM (коллекция «Color · Dark»): фон #0f1113, панель #16181b, голубой #6f9be3 для действий, розовый #da7bb8 для активного пункта меню, счётчиков и вывода. Шрифт — Inter, если установлен, иначе системный SF.
- Экран гео: карточки «Вчера» / «Месяц» с CPD и спендом; CPD окрашен по статусу к бенчу; график с итогами и строкой выбранного дня; алармы гео; таблица байеров, отсортированная по переплате.
- Бенч: значение по умолчанию в `config.ts`, изменение пользователя — в UserDefaults приложения (центы). Причина: бенч — рабочее решение COO, его меняют чаще, чем выходят версии.
- «Вчера» — всегда вчерашний день по Москве; нет данных — прочерки (уточнено COO 19.11.2026: не подставлять предыдущий день). Частично внесённый день помечается плашкой. Правило — в `docs/data-contract.md`.

## Последствия

- Бенч из приложения пока не попадает в таблицу и другим людям не виден. Когда появится CRM (вариант 3), бенчи переедут в справочник гео с историей изменений.
- Светлой темы нет: COO выбрала тёмную.
