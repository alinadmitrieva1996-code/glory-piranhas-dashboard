# ADR 0002. Данные из Google Sheet через Apps Script с секретным ключом

- Статус: принято
- Дата: 2026-11-18

## Контекст

Приложению нужно раз в час и по кнопке читать таблицу команды. Таблица приватная, в ней спенд. Пользователь не разработчик, настройка должна быть простой.

## Варианты

| Вариант | Настройка | Безопасность | Минусы |
|---|---|---|---|
| **A. Apps Script внутри таблицы, веб-приложение + ключ** | ~5 минут, без Google Cloud | Данные только по ключу; ключ в связке ключей macOS | Ссылка технически публичная, защита только ключом |
| B. Google Sheets API + вход через Google (OAuth) | ~15 минут, проект в Google Cloud Console | Лучшая: доступ по аккаунту | Сложнее настроить и поддерживать (OAuth-клиент, обновление токенов) |
| C. «Опубликовать в интернете» (CSV) | 1 минута | Нет: таблица открыта всем по ссылке | Недопустимо для финансовых данных |

## Решение

Вариант **A**. Скрипт сам находит блоки гео по заголовкам `BUYERn - XX`, поэтому новое гео подхватывается без правок кода. Ключ сравнивается за постоянное время, а его смена делается функцией `rotateKey()`.

## Последствия

- Если таблиц и пользователей станет много, переходим на вариант B. Тогда меняется только `DataClient` в Swift, контракт данных остаётся прежним.
- После правок скрипта нужно выпустить новую версию развёртывания (инструкция в `docs/setup-google-sheet.md`).
