# Подключение таблицы «Пираний» к приложению

Время: около 5 минут. Нужны права редактора таблицы.

## 1. Вставить скрипт

1. Откройте Google Sheet команды «Пираньи».
2. В меню выберите **Расширения → Apps Script**. Откроется редактор.
3. Удалите всё в файле `Code.gs` и вставьте содержимое [`apps-script/Code.gs`](../apps-script/Code.gs) из этого репозитория.
4. Нажмите 💾 «Сохранить».

## 2. Создать секретный ключ

1. В выпадающем списке функций вверху выберите **setup** и нажмите **Выполнить**.
2. Google попросит разрешения: «Проверить разрешения» → ваш аккаунт → «Дополнительно» → «Перейти к проекту» → «Разрешить». Скрипт получает доступ только к этой таблице.
3. Внизу откроется **Журнал выполнения** со строкой `Секретный ключ для приложения: …`. Скопируйте ключ.

Проверка: выберите функцию **preview** и нажмите «Выполнить». В журнале появится число строк и последние 5 строк. Если строк 0, проверьте, что листы называются `BUYER1`…`BUYER10`.

## 3. Развернуть как веб-приложение

1. Справа вверху нажмите **Развернуть → Новое развёртывание**.
2. Шестерёнка «Выберите тип» → **Веб-приложение**.
3. Укажите:
   - Описание: `Дашборд Пираньи`
   - **Выполнять от имени:** «Меня»
   - **У кого есть доступ:** «Все»
4. Нажмите «Развернуть» и скопируйте **URL веб-приложения**, который заканчивается на `/exec`.

> Доступ «Все» означает, что открыть ссылку может любой, но без ключа скрипт отвечает `unauthorized` и данных не отдаёт. Ключ хранится только в скрипте и в связке ключей вашего Mac.

## 4. Вставить в приложение

Откройте «Дашборд байеры» → ⌘, (или кнопка-шестерёнка) → вставьте ссылку и ключ → «Сохранить и обновить».

## Если что-то пошло не так

| Что видно в приложении | Что сделать |
|---|---|
| «Неверный ключ» | Заново скопируйте ключ из журнала `setup()` |
| «В скрипте таблицы ещё не создан ключ» | Запустите `setup()` |
| «Вместо данных пришла страница» | В развёртывании доступ должен быть «Все» |
| Цифры не меняются после правок скрипта | Развернуть → Управление развёртываниями → ✏️ → Версия: «Новая» → Развернуть (ссылка останется прежней) |
| Ключ мог утечь | Запустите `rotateKey()` и вставьте новый ключ в приложение |
