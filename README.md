# Пираньи: CPD по гео (приложение для Mac)

Дашборд быстрой реакции для команды «Пираньи» (Glory). Для каждого гео он показывает CPD и спенд за вчера и за месяц, сравнение с бенчмарком, график по дням и таблицу байеров. Данные берутся из Google Sheet команды: автоматически раз в час и по кнопке «Обновить» (⌘R).

```
Google Sheet ─(Apps Script, ключ)→ Swift: загрузка раз в час / ⌘R → кэш на диске
                                         └→ WKWebView: расчёты CPD (TS) → вкладки, график, байеры
```

## Как это устроено

| Часть | Где | Что делает |
|---|---|---|
| Скрипт таблицы | `apps-script/Code.gs` | Живёт внутри Google Sheet и отдаёт строки листов `BUYER1…BUYER10` в JSON по секретному ключу |
| Интерфейс и расчёты | `web/` (TypeScript) | Считает CPD в центах, статусы относительно бенча, рисует вкладки, график и таблицы |
| Mac-приложение | `macos/` (Swift, SwiftUI + WebKit) | Окно, меню, кнопка обновления, таймер раз в час, ключ в связке ключей macOS, кэш последних данных |
| Сборка | `.github/workflows/build.yml` | Тесты → сборка `.app` на macOS-сервере GitHub → ветка `builds` |

Подробнее о решениях: [docs/adr](docs/adr). Формат данных: [docs/data-contract.md](docs/data-contract.md).

## Установка для пользователя

1. Подключить таблицу по инструкции [docs/setup-google-sheet.md](docs/setup-google-sheet.md). Это займёт около 5 минут, а на выходе будут ссылка и ключ.
2. Скачать `Piranhas-macos.tar.gz` из ветки `builds` (или из Actions → последняя сборка → Artifacts), распаковать и перенести `Piranhas.app` в «Программы».
3. При первом запуске macOS может сказать, что разработчик не проверен. В этом случае: правый клик по приложению → «Открыть» → «Открыть». Это нужно сделать один раз.
4. В окне «Подключение Google Sheet» вставить ссылку и ключ.

## Разработка

Требования: Node 22.18+, Xcode 15+ или Command Line Tools (Swift 5.9+), macOS 13+.

```bash
# интерфейс
cd web
npm install
npm run check          # типы (tsc strict) + тесты (node:test) + сборка в web/dist

# приложение
cd ../macos
swift test             # тесты логики загрузки и кэша
PIRANHAS_WEB_DIR=../web/dist swift run   # запуск без сборки .app

# готовый .app
cd ..
./macos/scripts/build-app.sh   # → dist/Piranhas.app, dist/Piranhas-macos.tar.gz
```

Где что менять:
- **Бенчмарки и список гео:** `web/src/config.ts`.
- **Какие листы и колонки читаются:** `CONFIG` в `apps-script/Code.gs`.
- **Частота автообновления:** `RefreshPolicy.interval` в `macos/Sources/PiranhasCore/SnapshotStore.swift`.

Правила:
- деньги считаются только в целых центах;
- общего CPD команды нет, гео не смешиваются;
- каждое изменение логики сопровождается тестом;
- решения записываются как ADR.
